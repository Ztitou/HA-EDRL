# HA-EDRL

This repository provides the preprocessed hypergraph datasets and pretrained NHNE embedding vectors used in the experiments of the following paper:

**HA-EDRL: A Hypergraph-Aware Evolutionary Deep Reinforcement Learning Framework for Influence Maximization**

## Repository Contents

- **Preprocessed Hypergraphs:** The processed hypergraph datasets used in our experiments.
- **Pretrained NHNE Embeddings:** The pretrained node embedding vectors generated by NHNE for the corresponding datasets.

## Data Preprocessing

The preprocessing procedure includes removing duplicate hyperedges, eliminating duplicate nodes within each hyperedge, and removing hyperedges containing fewer than two nodes.

## Code Availability

The complete source code of HA-EDRL, including the implementation of the proposed framework and baseline adaptations, will be made publicly available in this repository upon formal acceptance of the paper.
